Outlier Detective

Upload a CSV, or try the sample: see a column's spread on a number line, and inspect what's flagged.

Your file is processed entirely in your browser. It is never uploaded anywhere.

Normal value Outlier (beyond 1.5× IQR) IQR fence

What is happening?

Every dot is a value in the selected column, placed left-to-right by size. The two faint vertical lines are the IQR fences: 1.5× the interquartile range beyond the 25th and 75th percentile. Anything past a fence is colored as an outlier; click a red dot to see exactly how far it sits beyond the fence.

Under the Hood
CSV parsed in-browser↓Quartiles + IQR fences computed for the column↓Values plotted; anything past a fence marked as an outlier

Inputs

  • Any CSV with a header row

Processing

  • Quartile calculation
  • IQR outlier rule (1.5× IQR)

Output

  • Number-line plot
  • Outlier list with distance beyond fence

Technology

  • Vanilla JavaScript, FileReader API
