🧹 Data Cleaning & Quality

Missing Value Explorer

Upload a CSV, or try the sample: see exactly what's missing, and one reasonable way to handle it.

Your file is processed entirely in your browser. It is never uploaded anywhere.

Rows Missing This Column

What is happening?

For a numeric column, filling gaps with the median is a common, defensible default: it doesn't get pulled around by outliers the way a mean does. For a text column, the most frequent existing value is shown, but that's a much weaker default; missing categorical data is often better flagged for manual review than silently filled.

Under the Hood
CSV parsed in-browser↓Missing rows located per column↓Numeric → median suggested; text → most frequent value shown

Inputs

  • Any CSV with a header row

Processing

  • Per-column missing detection
  • Median (numeric) / mode (text) computation

Output

  • Missing count, missing rows, suggested fill

Technology

  • Vanilla JavaScript, FileReader API
