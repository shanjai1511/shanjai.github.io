What is happening?

This is a generic shape, not any one specific system: the load balancer / app servers / cache / queue / database / worker pool arrangement shows up, in some form, behind most services that need to handle real traffic. Knowing each piece's actual job (and actual failure mode) is what makes "just add more servers" a meaningful answer sometimes, and a wrong one other times.
