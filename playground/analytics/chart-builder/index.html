📊 Data Analytics

Chart Builder

Pick X, Y and a chart type: build your own visualization.

Demonstration using a representative 20-row sample dataset.

What is happening?

All three chart types are rendered live from the same 20 rows, hand-built as inline SVG: no charting library. Line and bar sort rows by the X value first, since neither reads well on unsorted data.

Under the Hood
X / Y / chart-type selection↓Rows sorted by X (line and bar)↓SVG shapes generated and drawn

Inputs

  • 5 numeric columns, 20 rows

Processing

  • Linear scaling to pixel coordinates

Output

  • Scatter / line / bar chart

Technology

  • Vanilla JavaScript
  • Hand-built inline SVG
