📊 Data Analytics

Correlation Explorer

See which numbers move together, and which don't.

Correlation Matrix

Demonstration using a representative 20-row sample dataset (price, units sold, ad spend, rating, returns).

What is happening?

Correlation measures how closely two numeric columns move together, from −1 (perfectly opposite) to +1 (perfectly together). Correlation does not imply causation: two things can move together because one causes the other, because a third factor drives both, or by coincidence.

Under the Hood
Sample dataset (bundled) ↓ Pearson correlation for every numeric column pair ↓ Matrix rendered, pair selection redraws the scatter plot

Inputs

  • 5 numeric columns, 20 rows

Processing

  • Pearson correlation coefficient

Output

  • Correlation matrix
  • Scatter plot per pair

Technology

  • Vanilla JavaScript
  • Hand-built inline SVG chart
