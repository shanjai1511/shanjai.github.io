Analyze My Data

Upload a CSV, or try the sample — get an automatic column-by-column profile.

Your file is processed entirely in your browser. It is never uploaded anywhere.

Column Profile

What is happening?

Every column is classified as numeric or text using the same >60%-parses-as-a-number rule the Data Quality Checker uses. Numeric columns get min/max/mean/median; text columns get their most frequent value and how many distinct values exist — the kind of first-look profile that usually comes before any real analysis.

Under the Hood
CSV parsed in-browser↓Each column classified as numeric or text↓Column-appropriate summary computed

Inputs

  • Any CSV with a header row

Processing

  • Type classification
  • Min/max/mean/median (numeric)
  • Mode + cardinality (text)

Output

  • Dataset overview
  • Per-column profile

Technology

  • Vanilla JavaScript, FileReader API
