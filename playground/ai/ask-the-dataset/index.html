🤖 AI & Machine Learning

Ask the Dataset

Pick a question. See the real calculation behind the answer.

Demonstration using a representative 20-row sample dataset.

What is happening?

This isn't free-text natural language processing: that would need a real model and a backend this static site doesn't have. What it is: a fixed set of real questions, each wired to a genuine calculation over the data (mean, correlation, a filter, a lookup), computed fresh every time you click, with the exact formula shown so nothing is a black box.

Under the Hood
Question selection↓Corresponding calculation run over the live dataset↓Answer + formula shown together

Inputs

  • 5 numeric columns, 20 rows

Processing

  • Mean / correlation / filter / lookup, depending on the question

Output

  • Plain-language answer with the calculation shown

Technology

  • Vanilla JavaScript
