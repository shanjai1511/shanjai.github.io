Digital Menucard

QR-triggered menus with real-time updates and restaurant analytics

A restaurant menu is really just a database that hasn't been told it's allowed to be one. Digital Menucard treats it that way: instant to update, free to print, and quietly gathering analytics along the way.

TypeIndependent Project
Print Cost₹0
StackHTML · CSS · JavaScript
SourceView on GitHub ↗

The idea came from watching how much friction a simple price change caused for small restaurants: a new print run, a delay of days, a stack of outdated menus that had to be quietly retired. None of that complexity is inherent to "showing a menu"; it's just an artifact of the menu being printed on paper instead of served from a database.

So the system is deliberately simple: a QR code links to a web app, the web app reads from a dynamic backend, and an admin panel lets an owner edit content without touching code. The interesting part isn't the QR code; it's that removing paper from the loop turns every menu change from a logistics problem into a form submission.

The Build

Challenge

Restaurants reprinted paper menus for every change: slow, costly, and wasteful in fast-paced environments where prices and availability shift often.

Approach

QR code–linked web app where menus are served dynamically; owners update content instantly through an admin panel without needing technical expertise.
